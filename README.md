# Atelier Rental — Django starter

Минимальный каталог одежды для аренды и индивидуального пошива.

## Что уже есть

- Django + PostgreSQL + Docker Compose
- PostgreSQL хранит данные локально в `./data/postgres`
- Каталог: готовые изделия / аренда и made-to-order
- RU / EN переключатель через jQuery + AJAX
- Главная, Каталог, О нас, Контакты
- Django Admin
- Цвета изделия
- 360° viewer: drag мышкой/пальцем по набору кадров
- Календарь занятых дат
- AJAX бронирование с серверной проверкой пересечений
- Демо-данные и автоматически генерируемые демонстрационные 360° кадры

## Быстрый запуск

```bash
cp .env.example .env
docker compose up --build
```

Открыть:
- сайт: http://localhost:8000
- admin: http://localhost:8000/admin

Создать администратора:

```bash
docker compose exec web python manage.py createsuperuser
```

Остановить:

```bash
docker compose down
```

Полностью удалить локальную БД:

```bash
docker compose down
rm -rf data/postgres/*
```

## Как устроены 360° фото

В Admin у каждого изделия есть inline `Фото / 360 кадры`.
Для каждого кадра указываются:
- цвет
- изображение
- угол (0..359)
- порядок

На странице товара JS выбирает набор кадров текущего цвета и меняет кадр при горизонтальном drag.

## 5 этапов разработки

1. **Foundation** — Docker, Django, PostgreSQL, RU/EN, базовые страницы и admin. Уже в архиве.
2. **Catalog** — категории, изделия, ready-made / made-to-order, цены, размеры, цвета, фильтры. Уже базово в архиве; дальше можно расширить.
3. **Booking** — календарь, занятые даты, AJAX бронь, статусы в admin. MVP уже есть; дальше добавим подтверждения/уведомления.
4. **Product experience** — фотографии по цветам, 360° viewer, улучшенная карточка, мобильная версия. MVP уже есть; дальше подключим реальные фото.
5. **Polish & production** — финальный дизайн, формы, SEO, Nginx/Gunicorn, почта, платежи/депозит при необходимости, production deploy.
